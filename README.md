# 🐾 PetHubProject

A web-based pet care and pet shopping platform that provides users with information about pets, pet products, and store locations.

## 🌐 Live Demo

🔗 https://lakshmipn-pethub.onrender.com

## 📌 About the Project

PetHubProject is a web application designed to provide a simple and user-friendly platform for pet owners and pet lovers.

Users can explore different categories such as dogs, cats, small pets, and store locations. The application also provides login and registration functionality.

## ✨ Features

- 🐶 Dogs section
- 🐱 Cats section
- 🐰 Small Pets section
- 🛒 Pet Store section
- 📍 Store Location
- 🔐 User Login
- 📝 User Registration
- 🏠 Home page
- 📱 User-friendly interface
- ☁️ Deployed on Render
